
## فاز ۲۰ — اصلاح ورود/ماندگاری، ثبت‌نام سخت‌گیرانه، ویزارد، ظاهر اندروید، قیمت‌ها و امنیت (۲۰۲۶-۰۹-۲۸)

**علت خروج خودکار کاربر:** endpoint تمدید توکن (`token/refresh/`) در بک‌اند اصلاً وجود نداشت و فرانت‌اند هر ۴۰۱ را فوراً logout می‌کرد. حالا `auth/token/refresh/` هست، `api/client.ts` با single-flight تمدید و تکرار درخواست می‌کند و فقط وقتی سرور refresh را رد کند خروج می‌شود (قطعی اینترنت نشست را نگه می‌دارد). access = ۶ ساعت، refresh = ۱۸۰ روز با rotation.

### ورود و ثبت‌نام
- فقط موبایل + کد تأیید. حذف: گوگل/تلگرام، ورود ایمیلی از UI عمومی، نمایش کد تستی، آنبوردینگ (`Welcome`)، صفحهٔ `/register` قدیمی (redirect به `/login`).
- کاربر جدید: نام، نام خانوادگی، کد ملی (۱۰ رقم + چک‌سام). شهر خودکار «یاسوج».
- سخت‌گیری: `to_ascii_digits` (رقم فارسی→انگلیسی)، رد هر نویسهٔ غیرعددی در شماره/کد ملی، شماره `09xxxxxxxxx`؛ یکتایی شماره و کد ملی در بک‌اند.
- `/admin-login` (ایمیل+رمز، فقط ادمین) و `/driver-login` جدا؛ لینکی به آن‌ها در UI عمومی نیست.
- کاربر بدون حساب از اولین اجرا «مهمان» است (`store/auth.ts`)؛ فقط ثبت نهایی درخواست/کیف‌پول ورود می‌خواهد. بعد از ثبت‌نام، درخواست ذخیره‌شدهٔ ویزارد خودکار ثبت می‌شود (`autoSubmit`).

### ویزارد
گروه‌های کشویی + جستجو، وزن دقیق قابل ویرایش (فقط رقم)، انتخاب روز (امروز تا ۷ روز) و ساعت (۸ تا ۲۱، حداقل ۲ ساعت بعد)، دکمهٔ «مرحله بعد» بالای نوار پایین.

### ظاهر
نوار پایین مات (بدون backdrop-filter در کل اپ)، `viewport-fit=cover` در بیلد اندروید حذف و `SystemBars insetsHandling: native` (محتوا زیر دوربین/نوار وضعیت نمی‌رود)، لوگوی جدید (وب/PWA/اندروید/splash روشن)، `ErrorBoundary`، صفحهٔ `/about`، حذف اسکن دوربین از UI و DemoBadge.

### قیمت و مواد (`seed_demo.py`)
- کاتالوگ خانگی/اداری: ۳۵ قلم فعال؛ مواد صنعتی/کارشناسی/برنج/برد/لاستیک/چوب پنهان (نه حذف).
- قیمت خرید از شهروند = ۶۰٪ قیمت بازار (`CITIZEN_SHARE`). تخمین تقسیم ۴۰٪ باقی: راننده ۱۸٪، سبزینو ۱۴٪، ذخیرهٔ مالیات/هزینه ۸٪. **این‌ها تخمین‌اند؛ نرخ مالیات را با حسابدار تأیید کنید. قیمت واقعی کارخانه در دست نیست.**
- `sync_content` (دستور جدید، امن روی دیتابیس واقعی): مواد/قیمت‌ها + متن پروژه‌های اثر سبز. مبلغ جمع‌شدهٔ ساختگی فقط برای پروژه‌های بدون مشارکت واقعی صفر می‌شود.
- `/pricing/` قیمت مواد غیرفعال را نشان نمی‌دهد.

### امنیت
Throttle (`otp_request` 40/min، `otp_verify` 60/min، `login` 20/min به‌ازای IP — عمداً بالا به‌خاطر NAT مشترک اپراتورهای ایران؛ محافظ اصلی «هر شماره» است: ۳۰ ثانیه فاصله + ۶ کد در ساعت)، پیام ورود یکسان (جلوگیری از enumeration)، classify-waste دوباره نیازمند ورود، هشدار `SECRET_KEY`/`DEBUG` ناامن.

### هنوز باز / ریسک‌ها
- **OTP تستی:** با `OTP_TEST_MODE=True` و کد ثابت، هر کسی با هر شماره‌ای می‌تواند وارد/ثبت‌نام شود. فقط برای تست؛ قبل از انتشار عمومی پیامک واقعی را وصل کنید.
- **سرور:** روی PythonAnywhere حتماً `DEBUG=False` و `SECRET_KEY` واقعی در env بگذارید.
- تست‌نشده: بیلد Gradle، ناحیهٔ امن زیر دوربین و Back روی گوشی واقعی، علت بستن اپ هنگام «ورود» (احتمالاً با بازنویسی صفحهٔ ورود رفع شد؛ در غیر این صورت Logcat).
- مرحلهٔ ۲ (انجام نشده): نقشهٔ یاسوج با ۳ ایستگاه، چالش‌های میدانی، انیمیشن لوگو، فونت، داشبورد راننده/ادمین (فعلاً فقط ورود جدا).

### دیپلوی
```
cd ~/sabzino/backend && workon sabzino-env && git pull && pip install -r requirements.txt
python manage.py migrate
python manage.py sync_content
```
سپس Reload از تب Web. مهاجرت جدیدی در این فاز نیست. برای اپ: `npm install && npm run build -- --mode android && npx cap sync android` و ساخت APK.

### افزوده‌های بعدی فاز ۲۰ (۲۰۲۶-۰۹-۲۸، بعد از تست روی گوشی)
- **علت «شهر شیراز و نقشهٔ شیراز»:** ماندگاری شهر انتخاب‌شدهٔ نسخهٔ قبلی روی گوشی + حساب قدیمی با شهر «شیراز». حالا `LAUNCHED_CITIES` (بک‌اند: `settings.LAUNCHED_CITIES`، فرانت‌اند: `store/auth.ts`) فقط یاسوج است؛ هر شهر دیگر به یاسوج برمی‌گردد و بک‌اند برای محدودهٔ سرویس هم `core.geo.service_city_name` را به‌کار می‌برد.
- **علت «ثبت نهایی کار نمی‌کند»:** بک‌اند فاصلهٔ آدرس را با شهر ثبت‌شدهٔ حساب می‌سنجید (کاربر شیراز + آدرس یاسوج = ۱۵۳ کیلومتر خارج از محدوده)، و خطای ساخت آدرس در UI هیچ‌جا نشان داده نمی‌شد. هر دو رفع شد؛ اکنون هر خطا با متن روشن نمایش داده می‌شود.
- **آدرس:** بدون کد پستی؛ پلاک/واحد اجباری و توسط کاربر پر می‌شود؛ آدرس خودکار از نقشه کوتاه است (شهر، خیابان، محله). نقشه فقط داخل یاسوج (`maxBounds`)؛ GPS بیرون از یاسوج رد می‌شود.
- **مراکز بازیافت یاسوج:** ۳ مرکز (جمهوری، بلوار عدل، شصت‌متری) با `sync_content`. مختصات از نقشه گرفته شد و **تقریبی** است (پمپ‌بنزین روبروی جمهوری روی نقشه پیدا نشد)؛ از داشبورد مدیریت → مراکز بازیافت قابل اصلاح است. ایستگاه‌های نمونه غیرفعال می‌شوند (حذف نمی‌شوند).
- **پاک‌سازی نمونه:** `sync_content` جمع‌آورهای نمونه را آفلاین و کاربران نمونهٔ غیرمدیر را غیرفعال می‌کند و شهر همهٔ کاربران را یاسوج می‌گذارد.
- **داشبورد مدیریت:** منوی گروه‌بندی‌شده (کاشی در موبایل، نوار کناری در دسکتاپ)، نشان تعداد تأییدهای منتظر، بخش جدید «مراکز بازیافت» (افزودن/ویرایش با نقشه، فعال/غیرفعال). API: `/stations/?all=1`، `lookup_field=uid`، `city` قابل‌نوشتن.
- **امنیت — فوری:** حساب مدیر نمونه (`admin@sabzino.demo` / `Admin@12345`) در مستندات عمومی ثبت شده؛ روی سرور واقعی حتماً رمزش را عوض کنید: `python manage.py changepassword admin`.

### چالش‌های میدانی و مدیریت ماموریت‌ها از داشبورد (۲۰۲۶-۰۹-۲۸)
- **مدل جدید:** `rewards.FieldEvent` (عنوان، محل، تاریخ، ظرفیت، جایزه، ناهار، توضیح، فعال) و `FieldEventRegistration` (یکتا به‌ازای کاربر/چالش). مهاجرت: `rewards/migrations/0002_fieldevent_fieldeventregistration.py` (**روی سرور `migrate` لازم است**).
- **API:** `/rewards/events/` (لیست عمومی چالش‌های فعال و پیش‌رو؛ `?all=1` برای مدیر)، `POST/DELETE /rewards/events/{uid}/register/` (کاربر واردشده؛ ظرفیت و ثبت مجدد کنترل می‌شود)، `GET .../participants/` (فقط مدیر). `ChallengeViewSet` حالا ModelViewSet است: خواندن عمومی، ساخت/ویرایش/حذف فقط مدیر.
- **کاربر:** صفحهٔ ماموریت‌ها بالای صفحه چالش‌های میدانی را با ظرفیت، جایزه و ناهار نشان می‌دهد؛ مهمان برای ثبت‌نام وارد می‌شود و به همان صفحه برمی‌گردد.
- **مدیر:** «ماموریت‌ها و چالش‌ها» دو زیربخش دارد: چالش‌های میدانی (ساخت/ویرایش/غیرفعال/حذف + فهرست شرکت‌کنندگان با «کپی فهرست») و ماموریت‌های امتیازی (ساخت/ویرایش/حذف).
- **seed:** `sync_content` سه چالش اولیه می‌سازد (آبشار یاسوج +۳۰ روز، تنگ تامرادی +۴۵ روز، ورودی یاسوج +۶۰ روز؛ ظرفیت ۴۰). **تاریخ‌ها، ظرفیت و جایزه پیشنهادی‌اند؛ قبل از انتشار از داشبورد نهایی‌شان کنید.** چالش هم‌عنوان دوباره ساخته/بازنویسی نمی‌شود.
